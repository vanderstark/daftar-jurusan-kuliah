## 1. Ilmu Pengetahuan Alam (Sains)

### 🔬 Biologi
| Kelebihan | Kekurangan |
|-----------|------------|
| Prospek kerja di bidang kesehatan, penelitian, farmasi | Gaji awal relatif rendah dibanding jurusan teknik |
| Dasar ilmu untuk profesi dokter, apoteker, peneliti | Butuh studi lanjut (S2/S3) untuk karir penelitian |
| Kontribusi nyata terhadap ilmu pengetahuan | Jam kerja laboratorium sangat panjang |
| Banyak peluang riset dan pendanaan | Persaingan ketat untuk posisi peneliti |

### 🧪 Kimia
| Kelebihan | Kekurangan |
|-----------|------------|
| Peminat sedikit = persaingan kerja rendah | Risiko bahaya laboratorium |
| Dibutuhkan di industri farmasi, pangan, minyak & gas | Gaji awal di Indonesia belum ideal |
| Skills analitis sangat dicari | Membutuhkan ketelitian tinggi dan kesabaran |
| Dasar untuk karir di forensik, material science | Sering harus lembur di lab |

### ⚛️ Fisika
| Kelebihan | Kekurangan |
|------------|------------|
| Dasar kuat untuk teknik dan penelitian | Karir langsung pasca-kuliah terbatas |
| Cocok untuk karir di IT, ingeniring, data science | Matematika sangat berat |
| Melatih logika dan pemecahan masalah | Kurang praktis untuk dunia kerja entry-level |
| Banyak beasiswa untuk studi lanjut di luar negeri | Butuh S2/S3 untuk posisi strategis |

### 🌌 Astronomi
| Kelebihan | Kekurangan |
|-----------|------------|
| Sangat unik dan memuaskan secara intelektual | Pilihan karir sangat terbatas di Indonesia |
| Berkembang pesat di era sains data | Butuh pendidikan sangat tinggi (S3 minimal) |
| Kontribusi terhadap eksplorasi luar angkasa | Observatorium dan fasilitas terbatas |
| Skills komputasi dan matematika tingkat tinggi | Gaji di Indonesia tidak kompetitif |

### 🌍 Geologi
| Kelebihan | Kekurangan |
|-----------|------------|
| Dibutuhkan di pertambangan, migas, konstruksi | Bekerja di lapangan dengan kondisi keras |
| Gaji tinggi di industri pertambangan | Risiko kecelakaan di lapangan |
| Kontribusi penting untuk mitigasi bencana | Lokasi kerja sering di daerah terpencil |
| Prospek global yang baik | Jurusan tidak populer = informasi terbatas |

### 📐 Matematika
| Kelebihan | Kekurangan |
|-----------|------------|
| Skills yang sangat dicari di data science, AI, finance | Materi sangat abstrak dan sulit |
| Gaji tinggi di bidang quant, actuarial, consulting | Tidak ada "hands-on" project nyata |
| Dasar untuk hampir semua bidang STEM | Butuh kemampuan berpikir abstrak tingkat tinggi |
| Banyak peluang remote work | Citra " jurusan sulit tanpa prospek" masih ada |

### 📊 Statistika
| Kelebihan | Kekurangan |
|-----------|------------|
| Permintaan tinggi di era big data | Matematika dan coding cukup berat |
| Gaji kompetitif di bidang data analytics | Kurang populer dibanding ilmu komputer |
| Bekerja di berbagai industri (banking, tech, health) | Butuh pemahaman domain industri yang kuat |
| Dasar kuat untuk machine learning | Sering dikira sama dengan "angka-angka saja" |

### 💻 Ilmu Komputer (Computer Science)
| Kelebihan | Kekurangan |
|-----------|------------|
| Gaji tertinggi di industri teknologi | Persaingan sangat ketat |

| Inovasi dan kreativitas tinggi | Risiko burnout karena deadline ketat |
| Dasar untuk AI, cybersecurity, blockchain | Banyak bootcamp = banyak pesaing non-gelar |

### 🔧 Teknik Informatika (Software Engineering)
| Kelebihan | Kekurangan |
|-----------|------------|
| Proyek nyata sejak kuliah | Kurikulum bisa tertinggal dari industri |
| Prospek kerja sangat tinggi | Butuh portofolio kuat untuk bersaing |
| Gaji kompetitif sejak awal karir | Banyak universitas = kualitas bervariasi |
| Cocok untuk entrepreneur teknologi | Kerja di bawah tekanan deadline tinggi |

### 🖥️ Sistem Informasi
| Kelebihan | Kekurangan |
|-----------|------------|
| Kombinasi IT dan bisnis = fleksibel | Tidak sedalam CS atau TI untuk coding |
| Dibutuhkan di semua departemen perusahaan | Bisa "tidak di sini tidak di sana" |
| Cocok untuk Business Analyst, PM | Perlu pemahaman bisnis yang kuat |
| Peluang karir di consulting | Kualitas kurikulum bervariasi antar kampus |

|-----------|------------|

| Kontribusi nyata terhadap infrastruktur | Bekerja di lapangan dengan risiko |
| Skills sangat transferable | Kurang relevan dengan tren digital terkini |

### 🏗️ Teknik Sipil

|-----------|------------|
| Kontribusi nyata terhadap pembangunan infrastruktur | Bekerja di lapangan dengan kondisi ekstrem |

| Skills yang sangat dibutuhkan di seluruh dunia | Butuh sertifikasi tambahan untuk naik jabatan |
| Peluang entrepreneur (kontraktor, konsultan) | Kerja fisik yang melelahkan |

### 🏭 Teknik Kimia

|-----------|------------|

| Kontribusi terhadap sustainability dan energi bersih | Jam kerja bisa sangat panjang |
| Skills analisis proses yang berharga | Butuh penyesuaian dengan lingkungan industri |

### 🏛️ Arsitektur
| Kelebihan | Kekurangan |
|-----------|------------|
| Kreativitas tinggi dan penghargaan seni | Proyek sangat panjang dan melelahkan |
| Gaji kompetitif untuk desainer berpengalaman | Butuh portofolio kuat dan jam terbang tinggi |
| Kontribusi nyata terhadap estetika kota | Kompetisi ketat untuk proyek bergengsi |
| Peluang entrepreneur sendiri | Butuh pengalaman bertahun-tahun untuk sukses |

### ⚙️ Teknik Mesin
| Kelebihan | Kekurangan |
|-----------|------------|
| Ilmu dasar yang sangat luas dan fleksibel | Materi berat dan kompleks |
| Dibutuhkan di semua industri manufaktur | Bekerja di pabrik dengan kondisi keras |
| Skills CAD dan desain yang sangat dicari | Butuh pemahaman material yang mendalam |
| Peluang di otomotif, dirgantara, energi | Kurang populer di Indonesia dibanding CS |

### 📡 Teknik Telekomunikasi
| Kelebihan | Kekurangan |
|-----------|------------|
| Prospek cerah di era 5G dan IoT | Teknologi berubah sangat cepat |

| Skills jaringan yang sangat dibutuhkan | Bekerja di tower dan area tinggi |

### 🔐 Keamanan Siber (Cybersecurity)
| Kelebihan | Kekurangan |
|-----------|------------|
| Permintaan sangat tinggi, gaji kompetitif | Butuh pemahaman sangat luas (network, OS, coding) |
| Karir sangat menjanjikan di era digital | Harus terus update dengan ancaman terbaru |
| Kontribusi penting terhadap keamanan nasional | Risiko hukum jika ada kesalahan |

## ⚠️ Catatan Penting

1. **Gaji bersifat relatif** — sangat tergantung lokasi, pengalaman, dan industri.
2. **Jurusan "jelek" tidak ada** — yang ada adalah jurusan yang tidak sesuai dengan minat dan bakat.
3. **Passion matters** — pilih jurusan yang sesuai minat, bukan hanya yang gaji tinggi.
4. **Skills > Gelar** — portofolio dan kemampuan praktis sering lebih bernilai dari ijazah.
5. **Terus belajar** — dunia kerja berubah, skills harus selalu diupdate.
6. **Studi lanjut** — banyak jurusan membutuhkan S2/S3 untuk karir strategis.
